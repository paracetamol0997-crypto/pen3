# Student Doubt Portal (DoubtDesk)

A simple, fast, and unified web application built with **Django** for students to post doubts and subject teachers to answer them.

---

## 🚀 ZERO-INSTALL / ZERO-INTERNET PORTABLE DESIGN

This project has been upgraded with **built-in vendored packages (`vendor/` folder)**. 
**No `pip install` step is needed at all!**

- All required packages (`Django`, `asgiref`, `sqlparse`, `tzdata`, `whitenoise`) are pre-extracted right into the `vendor/` directory.
- `manage.py` and `START_WEBSITE.bat` automatically read from `vendor/`.
- Even on a friend's laptop without `pip`, without administrative permissions, and without internet, **it runs immediately on the first click**.

---

## ⚡ How to Run in One Click (On Any Friend's Laptop)

1. Make sure Python is installed (Python 3.10+ from python.org with *"Add python.exe to PATH"* checked).
2. Simply double-click **[`START_WEBSITE.bat`](file:///c:/Users/Princ/OneDrive/Documents/pen3/START_WEBSITE.bat)** (or `run.bat`).
   - Starts the server directly.
   - Automatically opens the browser to `http://127.0.0.1:8000/`.
